# Language Roadmap

The following shows the planned order in which new Languages shall be added,
_unless_ the community of a Language farther down the list decides to show extraordinary support,
which might very well speed up the progress on that respective Language:

1. **English** (primary starting Language)
2. **German** (secondary starting Language)
3. **Spanish**
4. **Portuguese**
5. **French**
6. **Russian**
7. _More Languages as requested by the Community_
