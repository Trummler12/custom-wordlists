# Archive

Documents that are no longer accurate but worth keeping — early planning, superseded
designs, the reasoning behind decisions that have since moved on.

Nothing here describes the current state of the project. Each file carries a banner at the
top saying what it was and what replaced it; the banner matters because people arrive via
direct links and never see this folder.

Current documentation lives one level up in [`docs/`](..), in
[`CONTRIBUTING.md`](../../CONTRIBUTING.md), and in the JSON schemas under
[`schema/`](../../schema).
