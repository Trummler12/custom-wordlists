# Language flags: sources

The flags in this folder stand for languages, not countries. They mark the per-list toggle that switches a list to its entries in another language.

- `mixed/` and `linguistic/`: from Wikipedia's [Flag icons for languages](https://en.wikipedia.org/wiki/Flag_icons_for_languages).
- `country/`: the national flag from each country's Wikipedia article, e.g. [Germany](https://en.wikipedia.org/wiki/Germany).

All images are scaled down to a height of 192px. Which language uses which flag is set in `src/locale/flags.ts`.
